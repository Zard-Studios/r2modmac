# 0.7.5 Release

## News and improvements
- Added Outer Wilds modding support.
- Added game launch support via Sikarugir.
- Added support for PortingKit (Wineskin).
- Added mod configuration screen.
- Added custom mod support.
- Added "check updates" button.
- Added stream mode (censors username in folder paths).
- Added Windows support.
- Performance improvements.
- Improved the play button.

## Fix
- Fixed bug causing immediate download when importing a profile (in new mode).
- Fixed ip-rating issues.
- Fixed missing .dll files when downloading mods.
- Fixed profile sync bug.
- Fixed custom mods drag-and-drop bug across all screens.
