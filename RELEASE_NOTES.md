# v0.8.2 Release

## News and improvements
- Added safe profile updates with pending changes.
- Added selective Sync and Revert actions.
- Added resumable Apply operations.
- Added runtime repair for supported loaders.
- Added dedicated Updates and Sync views.
- Added update detection after importing modpacks.
- Added ReturnOfModding support.
- Added a freely resizable profile sidebar.
- Added smoother sidebar transitions.
- Added improved handling for long mod names.
- Added clearer deprecated-mod warnings.
- Added generated profile colors.
- Added optional text-only sponsored messages.

- Fixed partial installations.
- Fixed runtime detection for BepInEx.

- Fixed sidebar resize boundaries and tab alignment.
