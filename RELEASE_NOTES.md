# v1.0.0 Release

## New

* **Custom themes** - Create and edit your own themes with the new live theme editor.
* **Spotlight** - Open Spotlight from anywhere to quickly access games, profiles, settings, and profile actions.
* **Rebindable shortcuts** - Keyboard shortcuts can now be customized from Preferences.
* **Startup selection** - Choose a game and profile to open automatically at launch, skipping the selection screens.
* **Offline game list** - Your game list is now saved locally, so it opens instantly without waiting for the network.
* **Profile backups** - Each profile now keeps a backup of its mod configuration, included with profile export and restore.

## Improvements

* Long mod and game lists now scroll smoothly.
* The app remains responsive while mods are being installed.
* The cached mod list is now cleaned up instead of growing indefinitely.
* Troubleshooting logs can be collapsed.
* Missing game cover art is now fetched and displayed when available.
* UI improvements.

## Fixes

* The Play button no longer switches back to “Play” while Steam is still starting.
* BepInEx 6 installations are no longer incorrectly reported as incomplete.
* Stopping an Apply operation no longer removes mods that were already installed.
* Duplicated profiles no longer incorrectly claim mods applied by the original profile.
* Pressing Escape while typing in a text field now closes the field instead of the entire screen.
